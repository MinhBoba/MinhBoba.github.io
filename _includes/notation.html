Notation

Numbers and arrays

aScalar (italic lowercase)
\mathbf{x}Vector (bold lowercase), a column by default
\mathbf{A}Matrix (bold uppercase)
\mathsf{A}Tensor (sans-serif)
x_iElement i of vector x
A_{ij}Element in row i, column j
\mathbf{A}_{i,:}\;\; \mathbf{A}_{:,j}Row i; column j
\mathbf{I}_nIdentity matrix, n by n
\mathbf{0}\;\; \mathbf{1}All-zeros, all-ones vector
\mathbf{e}_iStandard basis vector (1 at position i)
\operatorname{diag}(\mathbf{a})Diagonal matrix with a on the diagonal

Linear algebra

\mathbf{A}^\topTranspose
\mathbf{A}^{-1}\;\; \mathbf{A}^{+}Inverse; Moore–Penrose pseudo-inverse
\mathbf{x}^\top \mathbf{y} = \langle \mathbf{x}, \mathbf{y} \rangleDot (inner) product
\mathbf{x} \mathbf{y}^\topOuter product
\mathbf{A} \odot \mathbf{B}Element-wise (Hadamard) product
\det(\mathbf{A})\;\; \operatorname{tr}(\mathbf{A})Determinant; trace
\operatorname{rank}(\mathbf{A})Rank
\|\mathbf{x}\|_2\;\; \|\mathbf{x}\|_1Euclidean norm; L1 norm
\|\mathbf{A}\|_FFrobenius norm
\lambda_i\;\; \mathbf{v}_iEigenvalue; eigenvector

Sets

\mathbb{R}\;\; \mathbb{R}^nReal numbers; real n-vectors
\mathbb{R}^{m \times n}Real matrices with m rows, n columns
\{0, 1\}\;\; \{1, \dots, n\}Discrete sets
[a, b]\;\; (a, b)Closed; open interval
\mathbb{S}^n_{+}Positive semidefinite n by n matrices

Calculus

\frac{dy}{dx}\;\; \frac{\partial y}{\partial x}Derivative; partial derivative
\nabla_{\mathbf{x}} fGradient of f with respect to x
\mathbf{J} = \frac{\partial \mathbf{f}}{\partial \mathbf{x}}Jacobian matrix
\nabla^2 f = \mathbf{H}Hessian matrix
\int f(x)\, dxIntegral

Probability

P(a)\;\; p(x)Probability; density
x \sim Px is drawn from P
P(a \mid b)Conditional probability
\mathbb{E}_{x \sim P}[f(x)]Expectation
\operatorname{Var}(x)\;\; \operatorname{Cov}(x, y)Variance; covariance
\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})Gaussian with mean μ, covariance Σ
D_{\mathrm{KL}}(P \,\|\, Q)KL divergence
H(x)Entropy

Data and models

\mathbf{x}^{(i)}\;\; y^{(i)}Input and target of example i
\mathbf{X} \in \mathbb{R}^{n \times d}Design matrix: n examples (rows), d features
\theta\;\; \boldsymbol{\theta}Model parameters
h_\theta(\mathbf{x})Hypothesis (model prediction)
J(\theta)\;\; \mathcal{L}Cost; loss
\alphaLearning rate
\sigma(z) = \frac{1}{1 + e^{-z}}Logistic sigmoid
\mathbb{1}\{\cdot\}Indicator: 1 if true, else 0
\log xNatural logarithm
