Linear Regression and Gradient Descent

Classical ML · Lecture 2

Classical ML
Regression
Optimization
Least squares, batch and stochastic gradient descent, and the normal equations.
Published

November 15, 2026

Full lecture: CS229 Lecture 2 on YouTube (Stanford has disabled embedding, so it opens on YouTube). The video above is a shorter companion on the same idea.

Key ideas

A linear hypothesis with x_0 = 1 for the intercept:

h_\theta(x) = \sum_{j=0}^{d} \theta_j x_j = \theta^\top x

The least-squares cost over n training examples:

J(\theta) = \frac{1}{2} \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right)^2

Gradient descent

Repeat until convergence, for every j at once:

\theta_j := \theta_j - \alpha \sum_{i=1}^{n} \left( h_\theta(x^{(i)}) - y^{(i)} \right) x_j^{(i)}

  • Batch gradient descent uses all n examples per step: an exact gradient, but slow on large data.
  • Stochastic gradient descent updates after each example: noisy, but it starts making progress immediately.
TipLearning rate

If J(\theta) goes up between iterations, \alpha is too large. Try dividing it by about 3 each time.

import numpy as np

def batch_gradient_descent(X, y, alpha=0.01, iters=1000):
    """X: (n, d+1) with a leading column of ones; y: (n,)."""
    theta = np.zeros(X.shape[1])
    for _ in range(iters):
        residual = X @ theta - y
        theta -= alpha * X.T @ residual / len(y)
    return theta

Normal equations

Setting \nabla_\theta J(\theta) = 0 gives a closed form:

\theta = (X^\top X)^{-1} X^\top y 

theta = np.linalg.solve(X.T @ X, X.T @ y)  # more stable than an explicit inverse
