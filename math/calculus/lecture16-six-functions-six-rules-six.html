6 Functions, 6 Rules, 6 Theorems

Calculus · Lecture 16

Calculus
Derivatives
Integrals
Series
The calculus toolkit on one page: six functions, six differentiation rules and six theorems, each with a worked example and where it is used.
Published

November 22, 2026

Study notes on Gilbert Strang’s review lecture (MIT OpenCourseWare, Highlights of Calculus): formulas, worked examples and real-world applications.

Six functions

Item and key formula Example Application
1. Power x^n
d/dx: n x^{n-1}
\int: \tfrac{x^{n+1}}{n+1}, fails at n = -1		 f = x^3 \to f' = 3x^2,\ \int = \tfrac{x^4}{4}
\int_0^2 x^3\,dx = \tfrac{16}{4} = \mathbf{4}		 Area and volume (x^2, x^3), cost curves, falling bodies (d = \tfrac12 g t^2), polynomial regression
2. Sine \sin x
d/dx: \cos x
\int: -\cos x		 Slope at 0: \cos 0 = \mathbf{1}
One arch: \int_0^\pi \sin x\,dx = [-\cos x]_0^\pi = \mathbf{2}		 Anything that repeats: sound, AC electricity, vibration, seasonal or time-of-day demand
3. Cosine \cos x
d/dx: -\sin x
\int: \sin x		 Slope at \pi/2: -\sin(\pi/2) = \mathbf{-1}
\int_0^{\pi/2} \cos x\,dx = [\sin x]_0^{\pi/2} = \mathbf{1}		 Same as sine (a shifted wave); oscillators, signal processing, Fourier analysis
4. Exponential e^{cx}
d/dx: c\,e^{cx}
\int: \tfrac{e^{cx}}{c}		 f = e^{2x} \to f' = 2e^{2x} (growth proportional to size)
\int_0^1 e^{2x}\,dx = \tfrac{e^2 - 1}{2} \approx \mathbf{3.19}		 Population growth, compound interest, radioactive decay, drug clearance, exponential smoothing
5. Logarithm \ln x
d/dx: \tfrac{1}{x}
\int: x \ln x - x
(\ln x fills the n = -1 gap)		 Slope at x = 2: \mathbf{1/2}
\int_1^e \ln x\,dx = [x \ln x - x]_1^e = 0 - (-1) = \mathbf{1}		 Log scales (dB, pH, Richter), log-loss in ML, log-likelihood (turns products into sums)
6. Step
0 for x < 0, 1 for x \ge 0
d/dx: delta (spike, area 1)
\int: ramp		 A switch turning on at t = 0
Ramp: \int_0^3 \text{step}\,dt = \mathbf{3}
Delta: a sudden kick (hammer hit) with total area \mathbf{1}		 Step: switch-on, policy change. Ramp: ReLU in neural nets, overtime cost past a threshold. Delta: impulse or one-time shock

Six rules of differentiation

Item and key formula Example Application
1. Sum
\left(\sum_i c_i f_i\right)' = \sum_i c_i f_i'		 (3x^2 + 5\sin x)' = \mathbf{6x + 5\cos x} Derivative of a total cost or weighted score, e.g. w_1 a + w_2 b
2. Product
(fg)' = f'g + fg'		 (x^2 \sin x)' = \mathbf{2x \sin x + x^2 \cos x} Revenue = price × quantity (both changing); power = voltage × current
3. Quotient
\left(\tfrac{f}{g}\right)' = \tfrac{f'g - fg'}{g^2}		 \left(\tfrac{\sin x}{x}\right)' = \tfrac{x\cos x - \sin x}{x^2} Rates and ratios: cost per unit, efficiency, utilization = busy time / total time
4. Chain
\tfrac{d}{dx} f(g(x)) = f'(g(x))\,g'(x)		 \tfrac{d}{dx}\sin(x^2) = \mathbf{2x\cos(x^2)}
(outer derivative × inner derivative)		 Backpropagation in neural networks; related rates (balloon radius as air is pumped in)
5. Inverse
(f^{-1})'(y) = \tfrac{1}{f'(x)}, y = f(x), f'(x) \ne 0		 y = e^x,\ x = \ln y \to \tfrac{dx}{dy} = \tfrac{1}{e^x} = \tfrac{1}{y}
(this proves (\ln y)' = 1/y)		 Derivatives of \ln, \arcsin, \sqrt{\phantom{x}}; converting “time per task” ↔︎ “tasks per time”
6. L’Hôpital
\lim\limits_{x\to a} \tfrac{f(x)}{g(x)} = \lim\limits_{x\to a} \tfrac{f'(x)}{g'(x)}
for 0/0 or \infty/\infty, if the right-hand limit exists		 \lim\limits_{x\to0} \tfrac{\sin x}{x} = \tfrac{\cos 0}{1} = \mathbf{1}
\lim\limits_{x\to0} \tfrac{e^x - 1}{x} = \tfrac{e^0}{1} = \mathbf{1}		 Limits that look like 0/0: continuous compounding → e^x; edge-case behavior of algorithms

Six theorems

Item and key formula Example Application
1. Fundamental Theorem
If f(x) = \int_a^x s(t)\,dt then f' = s;
\int_a^b f'(x)\,dx = f(b) - f(a)		 \int_0^3 2x\,dx = 3^2 - 0^2 = \mathbf{9} (no Riemann sums)
\tfrac{d}{dx}\int_0^x \cos t\,dt = \mathbf{\cos x}		 Velocity → distance; flow rate → total volume; demand rate → cumulative demand; PDF → CDF
2. Max–min / intermediate value
f continuous on [a, b]:
f(m) \le f(x) \le f(M) for all x, and f(c) = N for every N between f(m) and f(M)		 x^2 on [-1, 2]: max \mathbf{4} at x = 2, min \mathbf{0} at x = 0
Counterexample: the step on [-1, 1] never equals 0.5 (not continuous)		 Guarantees an optimum exists (basis of optimization); justifies bisection root-finding
3. Mean Value
If f is continuous on [a, b] and differentiable on (a, b), then f'(c) = \tfrac{f(b) - f(a)}{b - a} for some c in (a, b)		 x^2 on [0, 2]: average slope = 4/2 = 2; f'(c) = 2c = 2 \to \mathbf{c = 1}
Drive 120 km in 2 h → at some instant exactly 60 km/h		 Average-speed cameras; proving error bounds for numerical methods
4. Taylor series
f(x) = \sum\limits_{n=0}^{\infty} \tfrac{f^{(n)}(a)}{n!}(x-a)^n		 e^x \approx 1 + x + \tfrac{x^2}{2} \to at x = 0.1: \mathbf{1.105} (true 1.10517)
\sin x \approx x - \tfrac{x^3}{6}		 How calculators compute \sin, e^x, \sqrt{\phantom{x}}; \sin\theta \approx \theta for pendulums; gradient descent / Newton’s method
5. Taylor remainder
R_n(x) = \tfrac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}, c between a and x		 e^x at x = 0.1, n = 2: error = \tfrac{e^c}{6}\cdot 0.001, between 0.000167 and 0.000184
Actual error 0.000171 ✓		 Knowing how accurate an approximation is; choosing step size or number of terms in solvers
6. Binomial
(1+x)^p = \sum\limits_{k=0}^{\infty} \tbinom{p}{k} x^k, \lvert x \rvert < 1		 p = 2: 1 + 2x + x^2 (stops)
p = \tfrac12: \sqrt{1.1} \approx 1 + 0.05 - 0.00125 = \mathbf{1.04875} (true 1.04881)
p = -1: 1 - x + x^2 - \dots (never stops)		 Quick approximations, e.g. (1+r)^n \approx 1 + nr; relativity \gamma \approx 1 + \tfrac{v^2}{2c^2}; binomial distribution

Theorem formulation

1. Fundamental Theorem

\frac{d}{dx}\int_a^x s(t)\,dt = s(x), \qquad \int_a^b f'(x)\,dx = f(b) - f(a)

Part Meaning
s(t) Rate (speed) at moment t; continuous
\int_a^x s(t)\,dt Amount collected from a up to x
\tfrac{d}{dx} Slope of that amount, which gives the rate back
f'(x)\,dx One tiny step of change
f(b) - f(a) Total change: end minus start

2. Max–min / intermediate value

f(m) \le f(x) \le f(M), \qquad f(c) = N

Part Meaning
[a, b] Closed interval: both ends are included
continuous f No jumps; without it both claims can fail
f(m),\ f(M) Lowest and highest values, reached at points m and M
N Any value between the lowest and the highest
c A point where the function equals N (there may be several)

3. Mean Value

f'(c) = \frac{f(b) - f(a)}{b - a}

Part Meaning
f(b) - f(a) Total change in value
b - a Length of the interval
\tfrac{f(b) - f(a)}{b - a} Average slope, the line joining the two ends
f'(c) Slope at one single point
c Some point strictly between a and b; the theorem says it exists, not where
continuous on [a, b] No jumps, the ends included
differentiable on (a, b) A slope at every inside point. \lvert x \rvert on [-1, 1] has a corner at 0: its average slope is 0, but it never has slope 0

4. Taylor series

f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n

Part Meaning
f(a) Value of the function at the point a (the n = 0 term)
f'(a) Rate of change, the slope
f''(a) Curvature: how the slope bends
f^{(n)}(a) Behavior of the function at higher order n
(x-a)^n Distance from the point being approximated to a, at order n
n! Normalizes the coefficient: n derivatives of (x-a)^n give n!
\sum_{n=0}^{\infty} Add every order; equals f(x) where the remainder goes to 0

5. Taylor remainder

R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}

Part Meaning
R_n(x) Error left after stopping at order n
f^{(n+1)}(c) The next derivative, taken at c instead of a
c Unknown point between a and x; bound the error with the worst case
(n+1)! Grows fast, so more terms shrink the error
(x-a)^{n+1} Distance: the error is small close to a

6. Binomial

(1+x)^p = \sum_{k=0}^{\infty} \binom{p}{k} x^k, \qquad \binom{p}{k} = \frac{1}{k!}\prod_{j=0}^{k-1}(p-j)

Part Meaning
p Any power: whole, fraction or negative
\tbinom{p}{k} Weight of the x^k term
\prod_{j=0}^{k-1}(p-j) Multiply k factors, starting at p and dropping by one each time; hits 0 when p is a whole number below k, so the series stops
k! Normalizes the coefficient, as in Taylor series
\lvert x \rvert < 1 Needed for the endless sum to settle (not when the series stops)

The big picture

The functions describe how things behave (growth, cycles, switches); the rules let you differentiate complex models built from those pieces; the theorems guarantee that optimization and approximation actually work.

Notation

Numbers and arrays

a Scalar (italic lowercase)
\mathbf{x} Vector (bold lowercase), a column by default
\mathbf{A} Matrix (bold uppercase)
\mathsf{A} Tensor (sans-serif)
x_i Element i of vector x
A_{ij} Element in row i, column j
\mathbf{A}_{i,:}\;\; \mathbf{A}_{:,j} Row i; column j
\mathbf{I}_n Identity matrix, n by n
\mathbf{0}\;\; \mathbf{1} All-zeros, all-ones vector
\mathbf{e}_i Standard basis vector (1 at position i)
\operatorname{diag}(\mathbf{a}) Diagonal matrix with a on the diagonal

Linear algebra

\mathbf{A}^\top Transpose
\mathbf{A}^{-1}\;\; \mathbf{A}^{+} Inverse; Moore–Penrose pseudo-inverse
\mathbf{x}^\top \mathbf{y} = \langle \mathbf{x}, \mathbf{y} \rangle Dot (inner) product
\mathbf{x} \mathbf{y}^\top Outer product
\mathbf{A} \odot \mathbf{B} Element-wise (Hadamard) product
\det(\mathbf{A})\;\; \operatorname{tr}(\mathbf{A}) Determinant; trace
\operatorname{rank}(\mathbf{A}) Rank
\|\mathbf{x}\|_2\;\; \|\mathbf{x}\|_1 Euclidean norm; L1 norm
\|\mathbf{A}\|_F Frobenius norm
\lambda_i\;\; \mathbf{v}_i Eigenvalue; eigenvector

Sets

\mathbb{R}\;\; \mathbb{R}^n Real numbers; real n-vectors
\mathbb{R}^{m \times n} Real matrices with m rows, n columns
\{0, 1\}\;\; \{1, \dots, n\} Discrete sets
[a, b]\;\; (a, b) Closed; open interval
\mathbb{S}^n_{+} Positive semidefinite n by n matrices

Calculus

\frac{dy}{dx}\;\; \frac{\partial y}{\partial x} Derivative; partial derivative
\nabla_{\mathbf{x}} f Gradient of f with respect to x
\mathbf{J} = \frac{\partial \mathbf{f}}{\partial \mathbf{x}} Jacobian matrix
\nabla^2 f = \mathbf{H} Hessian matrix
\int f(x)\, dx Integral

Probability

P(a)\;\; p(x) Probability; density
x \sim P x is drawn from P
P(a \mid b) Conditional probability
\mathbb{E}_{x \sim P}[f(x)] Expectation
\operatorname{Var}(x)\;\; \operatorname{Cov}(x, y) Variance; covariance
\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma}) Gaussian with mean μ, covariance Σ
D_{\mathrm{KL}}(P \,\|\, Q) KL divergence
H(x) Entropy

Data and models

\mathbf{x}^{(i)}\;\; y^{(i)} Input and target of example i
\mathbf{X} \in \mathbb{R}^{n \times d} Design matrix: n examples (rows), d features
\theta\;\; \boldsymbol{\theta} Model parameters
h_\theta(\mathbf{x}) Hypothesis (model prediction)
J(\theta)\;\; \mathcal{L} Cost; loss
\alpha Learning rate
